# Tidepool

Tidepool es el proyecto personal de Alex Rivera: un mapa de calas con la altura de la marea. No es de Grayhaven y no usa datos del expediente.

A 29.10.2026 la capa de mareas no tiene nombre. La única decisión es no mezclarla con Harbor Permits aunque las dos hablen de costa.

Siguiente paso, anotado en la daily del 29.10.2026: una hora para elegir el nombre de esa capa.

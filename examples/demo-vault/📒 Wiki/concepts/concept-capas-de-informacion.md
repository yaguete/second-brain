# Capas de información

## Definición operativa

Una capa cartográfica o visual debe representar una sola variable. Separar las variables permite interpretar cada dimensión sin mezclar señales, ruido contextual o datos de naturaleza diferente.

## Implicaciones

La información relacionada con un expediente y la información sobre la marea deben mostrarse en capas diferenciadas. Mezclarlas en una única representación puede dificultar la lectura y hacer que el mapa resulte inútil. Este principio es relevante para el diseño de [[Tidepool]], donde la claridad de las variables representadas condiciona la utilidad del mapa.
